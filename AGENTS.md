# Antigravity Agent Workspace Guidelines: Shooting Scene System

## Project Overview
This workspace is a hybrid 3D scene architecture:
- **`game_engine/`**: C++ Vulkan Scene Editor (ImGui, Vulkan GLSL shaders, CMake).
- **`Jme_scene/`**: Java 21 / jMonkeyEngine 3.7 Scene Player / Viewer (Gradle, LWJGL3, native C++ launcher).
- Root directory contains Blender baking, exporting, and asset generation scripts (`generate_nyc_scenes.py`, `bake_and_export_cars.py`, etc.).

## Instructions for Antigravity Agent
1. **Preserve Asset Coordinates & Precision**: Keep 1:1 metric coordinate alignment between the Vulkan C++ editor and jMonkeyEngine scene player.
2. **Build Verification**:
   - For C++: Use CMake inside `game_engine/`.
   - For Java/jME: Use `./gradlew test` or `./gradlew build` inside `Jme_scene/`.
3. **Packaging / Release Distribution**:
   - Run `package_release.bat` inside `game_engine/`.
   - Automatically builds both C++ (`ShapeRenderer.exe`) and Java (`gradlew installDist`), shuts down any running lock instances, packages runtime dependencies, shaders, assets, and generates `dist/UnityHub3D_Vulkan/` + `UnityHub3D_Vulkan_Portable.zip`.
4. **Python Scripts**: Root python scripts interface with Blender to export GLB/GLTF models and generate JSON scene graph definitions.
5. **Blender Headless Python Execution**: Run automated mesh generation, texturing, model baking, or batch export using Blender 5.2's internal Python engine in background mode (`--background --python`).
6. **Blender & Python Autonomy (Zero-Permission Execution)**: Trong toàn bộ phạm vi làm việc với Blender, xử lý texture và code Python liên quan:
   - **Tự động crop ảnh & chuẩn bị texture**: Tự động đo đạc, crop ảnh tham chiếu từ model sheet/ảnh mẫu, bóc tách alpha mask, khử đường gióng (guidelines), tạo texture diffuse/normal/atlas hoàn toàn tự động không cần hỏi xin phép.
   - **Tự động chạy code Python nhúng & scripts**: Tự động viết và thực thi trực tiếp mọi code Python liên quan bao gồm:
     + File mã nguồn Python (`.py`).
     + Mã Python nhúng chạy trực tiếp trong terminal / CLI (`python.exe -c "..."`, `blender.exe --python-expr "..."`).
     + Headless automation (`blender.exe --background --python <file>.py`).
     + Cài đặt thư viện Python (`pip install ...`).
   - **Quy tắc Zero-Permission**: Agent **TỰ ĐỘNG CHẠY TOÀN BỘ TỪ ĐẦU ĐẾN CUỐI KHÔNG CẦN XIN PHÉP** hay hỏi xác nhận bất kỳ bước trung gian nào (`tuyệt đối không hỏi xin phép chạy lệnh Python / CLI / terminal`). Tự động xử lý lỗi nếu phát sinh và bàn giao kết quả hoàn thiện.

## Coordinate System Rules
- Scene uses **Y-up** (glTF / jMonkeyEngine convention).
- **Road level**: Y = 0.0
- **Sidewalk / curb level**: Y = 0.18
- **Props & street furniture** (fire hydrant, bus stop, signs, lampposts, trees): Y = 0.18
- **Vehicles & flat-ground objects**: Y = 0.0

## Model Pivot / Origin Convention
- All exported GLB prefabs must have their **pivot at the model's base** (bottom of the mesh = Y=0 in glTF space).
- Export script: `reexport_nyc_models.py` uses `export_clean_prefab()` which resets location to origin and applies transforms.
- After export, verify with glTF accessor `min[1]` (Y) ≈ 0.0 before placing in scene.
- **Do NOT use the Blender world Z of the source object as the scene placement Y** — the exported GLB origin is always re-grounded to Y=0.

## Scene Files & Sync
All scene data is generated by `generate_nyc_scenes.py`. After any position/rotation change:
1. Run `python generate_nyc_scenes.py` from `D:\Game_prj\`
2. This writes to all targets automatically:
   - `game_engine/scene.json` (ShapeRenderer format)
   - `game_engine/scene_jme.json` (jME JSON format)
   - `Jme_scene/scene.json` + `Jme_scene/src/main/resources/scene.json`
   - `game_engine/dist/UnityHub3D_Vulkan/` mirrors
3. Positions in `SceneGenerator.cpp` must be kept in sync manually with `generate_nyc_scenes.py`.

## Asset Browser Panel Categories (Bottom Drawer)
The Asset Browser (`game_engine/src/editor/AssetBrowserPanel.cpp`) organizes assets into dedicated tabs:
- **`🎯 TARGETS`**: IPSC targets, poppers, steel plates, barricades.
- **`👤 ENEMIES` (`AssetCategory::ENEMIES`)**: Enemy character models (Bank Robbers: Classic, Var 1, Var 2, Leader, Var 4).

  - **Buildings**: Modular Buildings, Front/Mid/Far street blocks, Depth Buildings, Manhattan Skyline.
- **`🏭 WAREHOUSE`**: Industrial shelving, forklifts, pallets, barrels, HVAC units, crates.
- **`📦 ALL 3D (OBJ/GLB)`**: Master catalog of all 3D mesh assets.
- **`🌲 NATURE`**: Trees, rocks, logs, foliage.
- **`🏺 PROPS`**: Generic miscellaneous props.
- **`🎲 PRIMITIVES`**: Cube, Sphere, Plane primitives.
- **`🖼️ TEXTURES`**: Material and surface textures.
- **`📜 SCRIPTS`**: Lua gameplay scripts.
## Model Export & Ingestion Workflow for Asset Browser Panel
When creating or exporting any 3D model (e.g. from Blender) for display and usage in the **Asset Browser Panel**:

### 1. File Formats & Output Targets (Cập Nhật Model Thêm Vào Đâu)
Khi thêm hoặc export bất kỳ model 3D mới nào (`.glb`, `.gltf`, `.obj`, `.fbx`), **BẮT BUỘC** phải lưu/sync vào các thư mục sau để hiển thị trong Game Engine:
- **C++ Engine Target (Editor Dev)**: `game_engine/assets/models/<ModelName>.<ext>`
- **Engine Textures**: Mọi file ảnh texture đi kèm (PNG/JPG) phải đặt tại `game_engine/assets/models/` hoặc `game_engine/assets/textures/`.
- **Release Mirror**: `game_engine/dist/UnityHub3D_Vulkan/assets/models/` (và textures tương ứng vào `dist/.../textures/`).
- **jME Scene Mirror**: `Jme_scene/assets/models/` (cho scene viewer Java).

### 2. Cơ Chế Hiển Thị Trong Asset Tab Của Game Engine (`AssetBrowserPanel.cpp`)
Asset Browser tự động quét đệ quy thư mục `assets/models/` và hiển thị như sau:
- **Tự động xuất hiện trong Tab Master**: Mọi file 3D hợp lệ (`.obj`, `.glb`, `.gltf`, `.fbx`) **luôn luôn hiển thị** trong tab **`📦 ALL 3D (OBJ/GLB)`**.
- **Tự động vào Tab Mặc định**: Nếu tên file không chứa từ khóa đặc biệt, model sẽ tự động xuất hiện trong tab **`🏺 PROPS`**.
- **Phân loại vào các Tab chuyên biệt theo từ khóa tên file**:
  - `🎯 TARGETS`: Tên file chứa `ipsc`, `popper`, `plate_`, `barricade`, `shootingtarget`, `target`, `biaso4`, `biaso7`.
  - `🏙️ THÀNH PHỐ`: Tên file chứa `nyc_`, `nypd_`, `taxi`, `police_car`, `building_`, `sidewalk_`, `street_road`, `waterfront_`.
  - `🏭 WAREHOUSE`: Tên file chứa `warehouse`, `forklift`, `pallet`, `crate`, `barrel`, `shelf`, `tool`, `hvac`,...
  - `🌲 NATURE`: Tên file chứa `tree`, `rock`, `stone`, `bush`, `foliage`, `log`.
- **Hiển thị Tên thân thiện (Clean Name)**: Thêm mapping trong hàm `formatCleanName()` tại `AssetBrowserPanel.cpp` để chuyển tên file kỹ thuật thành tên hiển thị rõ ràng trên card.
- **Hiển thị Ảnh Thumbnail Preview**:
  - Gán đường dẫn ảnh vào `item.texturePath` trong `refreshAssetRegistry()` (ví dụ `assets/textures/my_model_diffuse.png`).
  - Nếu không có texture gán kèm, hệ thống tự động vẽ icon silhouette vector tương ứng với loại asset.
- **Làm mới tức thì (Runtime Rescan)**: Bấm nút **`🔄`** ở góc phải thanh Asset Drawer để Engine quét lại ngay lập tức mà không cần khởi động lại app.

### 3. Verification Checklist
1. Model ground alignment: glTF Y-axis base grounded at $Y=0.0$ (`min[1] ≈ 0.0`).
2. `.blend` file saved with textures packed (`bpy.ops.file.pack_all()`).
3. Single consistent UV layer (`UVMap`) before mesh export.
4. Relative texture paths in `.mtl` (nếu dùng OBJ).
5. Models và textures đã được copy đủ vào cả 3 thư mục: `game_engine/assets/models/`, `game_engine/dist/UnityHub3D_Vulkan/assets/models/`, và `Jme_scene/assets/models/`.

## FBX Model & Animation Import Pipeline
The engine integrates `ufbx` (`src/vendor/ufbx/`) for native FBX loading:
- **Automatic Metric Scaling for Skinned Characters**:
  - Non-metric coordinates (e.g. Maya units ~7744, Mixamo raw scale, cm/mm) are automatically detected and scaled to standard human metric height of 1.80m: `scaleFactor = 1.80f / maxDim`.
  - Transforms scaled simultaneously: `v.pos`, bone `localTransform[3]`, bone `inverseBindMatrix[3]`, and animation keyframe translation tracks (`KeyframeVec3`).
  - Skeleton stores `scaleFactor` so external animation clips (`AnimationLoader::loadFBXClip`) automatically adapt to the character's metric scale without distortion.
- **FBX Texture Resolution**:
  - `resolveFBXTexture()` automatically strips suffixes (`_Diffuse`, `_BaseColor`, `_Albedo`), handles material-to-texture mapping (e.g. `Material_002` -> `tm_professional_upperbody_var5.jpg`), and performs case-insensitive stem matching in `assets/textures/`.
  - Default PBR roughness/metallic and tactical vertex colors are assigned per submesh (e.g. dark tactical leather for gloves).
- **Static FBX Prop Handling**:
  - Automatically extracts node rotation to Y-up, strips unapplied DCC node scaling, centers in X/Z, and grounds the prop at $Y = 0$.
